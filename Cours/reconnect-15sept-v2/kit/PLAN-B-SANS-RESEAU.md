# Continuer avec ce qui est déjà disponible

Le deck HTML est autonome. Le projet web peut fonctionner localement si ses dépendances et ses jeux de données sont déjà présents. Un agent cloud ne devient pas local quand sa connexion échoue.

| Besoin | Repli possible | Ce que le repli ne prouve pas |
|---|---|---|
| Lire le cours | index.html ou le PowerPoint | Installation des outils |
| Consulter une documentation | Copie datée, README ou types du paquet local | Fraîcheur de la documentation distante |
| Montrer une orientation | Fiches et traductions locales vérifiées | Intégration réelle d’un LLM |
| Contacter une structure | Coordonnées déjà sourcées | Validité actuelle sans nouvelle vérification |
| Voir une carte | Afficher l’adresse et un lien préparé | Ouverture du service cartographique |
| Développer | Relire et modifier manuellement, valider localement | Disponibilité du modèle distant |
| Partager | Garder les fichiers et branches localement | Publication GitHub ou fusion distante |

## Avant la séance

- Vérifier le démarrage du projet et la présence des dépendances.
- Préparer les copies de pages avec URL et date d’origine.
- Garder un petit jeu de démonstration relu, sans donnée personnelle d’usager.
- Choisir avec le PO le mode connecté si l’endpoint serveur est prêt, sinon le mode sans IA.
- Conserver le ticket, le contrat et les décisions utiles dans le dossier.

## Si les sources manquent

Réduire la démonstration aux données disponibles avec l’accord du PO. Un cas d’école peut être créé s’il est clairement présenté comme fictif ; il ne doit pas se faire passer pour une structure réelle ni comporter un contact déduit. Ne jamais compléter les coordonnées à partir de la seule mémoire du modèle.

## Ce que l’on annonce pendant la démo

« Cette réponse est préparée dans le jeu local, en mode sans IA. Voici la source et sa date de consultation. La connexion LLM, l’ouverture des liens distants et les vérifications non effectuées restent à réaliser. »

Adapter la phrase à ce qui a réellement été montré. Aucun modèle local n’est présumé installé ou testé dans ce kit.
