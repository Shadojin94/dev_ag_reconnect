# Installer le kit

1. Ouvrez le dossier racine de l’application, par exemple « Projet App Web ».
2. Copiez les trois dossiers de `.claude/skills/` dans son `.claude/skills/` ; ajoutez-les sans remplacer une configuration existante.
3. Copiez TICKETS-DEMAIN.md, CONTRAT-DONNEES.md et `wiki/` à la racine ; fusionnez CLAUDE-exemple.md et CLAUDE-wiki.md dans votre CLAUDE.md existant.
4. Ouvrez Claude Code CLI dans ce dossier, ou une session locale Desktop dans l’onglet Code sur ce même projet.
5. Tapez `/prompt-5 Afficher les organismes du jeu validé` ; contrôlez les cinq blocs, puis ouvrez TICKETS-DEMAIN.md.

Les skills sont fournis comme fichiers. Leur découverte et leur exécution sur les postes apprenants restent à tester. Le workflow affiche sa reformulation et attend « ok » avant toute implémentation.

Voir NOTICES-OUTILS.md pour les branchements ; SOURCES.md pour leur origine et leurs limites.
