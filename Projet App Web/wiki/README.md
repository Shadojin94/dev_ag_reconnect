# Wiki Reconnect

1. Déposez les copies des sources dans raw/ avec URL et date d’origine.
2. Gardez les originaux ; une extraction peut contenir des erreurs.
3. Ingest : faites proposer une synthèse dans pages/.
4. Reliez chaque affirmation importante à sa source.
5. Query : interrogez les pages et demandez les liens utilisés.
6. Signalez les informations manquantes ou contradictoires.
7. Lint : recherchez pages isolées, liens cassés et dates absentes.
8. Après validation, mettez à jour index.md et log.md.
9. Ne copiez ni secret ni dossier personnel d’usager.
10. Le wiki est local ; l’agent qui le maintient peut nécessiter le réseau.
